# 基于原书的 DeepSeek 连续问答

## 当前真实状态（2026-10-03）

本机已接入真实 DeepSeek。此前离职、租房、密码安全和书外问题实测通过；本轮增加存钱、带历史的追问、工作压力、书外问题四例，真实模型响应和原书引用校验均通过。记录在 `output/qa-conversation-live-check.json`。这是本机核心 handler 的真实模型验收，不是公网登录、送达或收费验收。

公开 GitHub Pages 的会员 API 仍为 404；独立主站的 DNS/TLS、真实收码与商户验收尚未完成，不能把本机可用写成公网闭环已上线。当前本机预览在 4190，保留独立本机体验账号；它不是短信或邮箱认证。

## 用户体验

首页直接提问，回答下面「接着问」。旧回答不会因为追问、接口失败或停止生成而消失。每一轮可以展开原文、复制，或主动「收进我的指南」；「新对话」先确认再清空。当前页面保留最近 20 轮，传给模型的是最近最多 4 轮摘要，不把整段聊天无限发送。

当前对话只保留在页面内存，刷新或离开首页会丢失；没有自动云端聊天记录或浏览器正文存储。用户主动保存的私人指南和已确认情况由账号系统在服务端持久化、私文加密、按账号隔离。切换/退出账号清空当前私人对话与草稿，匿名开始后主动登录允许保留这次对话。

原书 650 条建议、34 个主题的阅读、场景检索、PDF、Obsidian 导出仍免费。A/B/C 不向普通用户展示，适用条件与具体风险保留。

## 检索与追问

服务端用中文生活场景/别名与领域意图、词频/IDF 加权、标题/摘要相关性门槛选择最多 6 条完整原文，不依赖收费 embedding 或外部向量数据库。固定测试集的 50 条生活问法核心命中率由 60% 提升至 100%，实际返回条目相关率由 41.78% 提升至 96.89%；10 条书外问题全部拒绝召回。仍有 6 条尾部关联误召回，离线分数不代表所有真实问题都准确。

追问附带前轮问题、每步短摘要和已核对原书 ID；「第二步」只聚焦对应步骤的原文，不重新回答全部主题。历史是用户携带的不可信资料，不是 system/assistant 特权消息或已经核验的书内事实。最终结论仍必须被本轮完整原文支持。切换主题不把上一话题的个人情况当作新问题事实。

无书内依据时直接返回不足，不调用收费模型。服务端校验 JSON、截断状态及每项引用，前端再以本地原书快照校验。合法引用不保证语义完全正确，也不代表政策已经联网核实。

## 本机启动与验收

1. 在本机配置被 Git 忽略的 `.env.local`，设置 `DEEPSEEK_API_KEY`。不要发到聊天或命名为 `VITE_` 变量。
2. `npm run dev -- --host 127.0.0.1 --port 4190 --strictPort`。开发预览提供同源 API；真实登录通道看 `/api/membership` 的两个配置布尔。
3. `npm run check`：静态构建、全部 mock/临时数据库回归、原文保真与来源检查，不会自动发验证码或创建收费订单。
4. 需要明确进行有限真实模型复查时，运行 `node --env-file-if-exists=.env.local scripts/qa-conversation-live-check.mjs`。只发送脚本内四个合成问题，实际可能产生模型费用；不发码、不创建订单、不访问个人指南数据库。
5. 固定离线检索评估：`node scripts/retrieval-eval.mjs`。

默认模型由 `DEEPSEEK_MODEL` 指定（当前 `deepseek-flash`）；状态接口只返回是否配置，不输出密钥。不得把未执行真实模型的 mock PASS 称为接通。

## 会员主站上线

会员和付款必须在独立 HTTPS 同源主站运行，不能把登录会话跨域挂在 GitHub Pages 后面。用单实例 Node + SQLite 首版，准备独立 origin、持久私人 DB、秘密和系统用户；生产运行会强制会员计量、禁用 demo、核对邮件/短信通道，缺项拒绝启动。

发布入口、支付开放闸门、加密备份/恢复、Nginx/systemd 模板与实测记录见 `docs/PRODUCTION-RELEASE.md`。GitHub Pages 保留公开阅读/下载入口，不声称已开会员收费。

已有 Worker 和 Sites 包装继续保留，能运行公共原书问答核心；它不提供 Node SQLite 会员或私人指南服务，不能代替会员主站。不要把前端问答地址指向一个绕过会员扣次的公开 API。

## 边界和费用保护

- 每题 500 字、8KB 请求；历史最多 4 轮/6KB，Unicode 字符与 UTF-8 字节分别校验。
- 10 秒读体、45 秒上游超时、单实例每客户端 12 次/分钟、全局 60 次/分钟、3 并发、最多 1000 计数桶。
- 当前问题、有关原文和追问摘要会发送给 DeepSeek；不承诺第三方服务商不保留。个人指南完善只发送用户明确选定、已确认的情况。
- 会员成功回答扣一次，不足/失败/取消释放预留。同请求重试不重复计量；已释放的取消请求自动换新 ID 重试一次，待处理或已计量请求不擅自换 ID。
- 限流为单实例内存保护，不能代替生产网关、费用告警和每日模型预算。多实例须重新设计持久限流和数据库层，不能只加进程数量。
