# 自主优化记录 · 2026-10-03

目标：保留选定的首页视觉，修复真实交互和手机问题，降低首页加载开销，交付稳定的本地版本。

## 本轮完成

- 问答：例题点击即问；停止后可立即编辑和重试；新问题替代旧请求；迟到结果不覆盖当前答案。步骤与来源折叠更紧凑，完整内容和适用条件仍能展开。
- 图谱：拖动不反复重建尺寸观察器；缩放后点选准确，选中的条目回到可见区；触屏滚动不误触。全部相关建议、条目切换和加载重试均可用。小屏预览卡放在画布下方。
- 原文：分享链接始终指向正确条目；复制失败时提供可选链接；返回、前进、直接链接和刷新恢复一致；收藏提示只属于当前条目。
- 入口：`#library` 正确打开检索；普通推广参数不会误开检索；按场景找保持场景导航。支持默认 Pages 子路径和 `PUBLIC_BASE_PATH=/` 根域构建。
- 性能：会员与个人指南页面按需加载，首页主 JS 从 521.29 降至 478.28 KB；全局登录弹窗保持可用。路由包加载失败可重试。

## 验证

106 项测试通过，650 条原文展示检查、797 处引用检查通过。浏览器覆盖实际模型问答、取消与替换、原文弹窗、收藏、分享、历史导航、图谱缩放与触屏、下载，以及桌面 1440、手机 390、平板 825 px。

视觉证据与验收见 [design-qa.md](../design-qa.md)，根域构建方法见 [DEVELOPMENT.md](DEVELOPMENT.md)。本轮验证的是本地开发版和生产构建，没有发布公网或进行实际收费。
