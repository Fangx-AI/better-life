# 独立指南阅读页

2026-10-04：按用户提供的目录式参考，将全部条款检索从首页移到独立阅读页。保留已选定的白底、珊瑚品牌、首页首屏、关系图谱、问答示例和下载区，不复制参考截图的蓝色品牌或不同条目数量。

## 页面分工

- 首页：介绍、直接提问、场景入口、展示和下载，不再渲染全部条款检索列表。
- 阅读页：桌面左侧章节目录，右侧总览、章节条目或单条完整正文。章节目录独立滚动，当前章节展开具体条目。
- 手机：目录展开/收起，选中后回到内容；不压缩成只能看一小块的双栏。
- 个人指南与会员：保持原有独立页面和账号、草稿保护逻辑。

条款详情直接展示在页面，不再用覆盖首页的弹窗。收藏、搜索、不花钱筛选、来源、分享链接和前后条目仍可用；收藏沿用浏览器 `better-life:saved`，不迁移或重置已有数据。

## 地址与兼容

采用现有 query 页面约定，适配静态 GitHub Pages，不依赖路径 rewrite：

- 总览：`?view=library`
- 本章：`?view=library&chapter=15`
- 本条：`?view=library&chapter=15#entry-15-1`
- 搜索：`?view=library&q=押金`
- 原有 `?chapter=15`、`?q=押金`、`#library`、`#entry-15-1` 仍进入阅读页。
- 旧 `grade` 只用于兼容阅读入口，不会产生任何等级筛选，也不会被写入新链接。
- `view=guides` 和 `view=pricing` 优先于旧原书参数，防止误跳离个人页面。

首页阅读入口用真正的链接；阅读页内部章节/条目采用 `pushState`，前进、返回和刷新均按地址恢复。详情返回保留原搜索列表地址，但从地址和浏览器状态读取的返回目标只允许本应用同源、同路径的阅读页，不能借此跳外站。

## 组件与验收

目录基于 Aceternity 官方 Sidebar registry，快照在 `docs/aceternity/sidebar.json`；固定展开桌面目录和可键盘操作的手机目录是本项目适配。按钮、输入、筛选、卡片和阅读线仍沿用已有 Aceternity 组件，没有添加 UI 依赖。

变更验收：`npm run check`；浏览器验证首页入口、章节/条款、搜索、收藏持久性、原有链接、前进返回、手机目录与横向溢出、语料失败和重试。浏览器证据保存在 Git 忽略的 `output/playwright/`，不上传用户记录。

本次仅改变阅读结构，不发送验证码、调用收费模型或真实付款，不开放会员收款，也不部署公网。
