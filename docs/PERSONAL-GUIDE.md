# 我的高性价比人生指南

## 服务是什么

**把自己的问题，变成一份用得上的生活指南。**

原书提供生活建议，用户提供自己愿意确认的情况。回答不是终点：把有用的答案收进自己的目录，改成自己的方案，记录下一步，后来有变化再继续完善。

会员的核心价值是更大的私人指南容量和持续整理能力，而不是出售免费原书，或保证某个人生结果。月度 ¥19、年度 ¥129 为当前实验定价，尚未开放真实购买。

## 已实现的使用路径

1. 首页直接提问，回答通过原书条目检索和引用校验。
2. 点击「收进我的指南」，选择新建或补充到已有指南。不是默认保存每一句话。
3. 在「我的指南」按生活主题和关键词找到自己的笔记，编辑正文，手动添加、勾选行动。
4. 在「我确认过的情况」写入自己明确确认的情况；不确定的内容不必填。每次继续问可另外选择要使用哪几项。
5. 在某篇指南中继续问：服务端只读取本人当前指南和本次选定的情况，再结合相关原书条目生成更新稿。
6. 更新稿可以修改、对照原稿、放弃；只有「确认采用更新稿」才成为新版本。生成后手动改过指南，旧更新稿不能覆盖新修改。
7. 历史版本可预览和恢复。恢复产生新版本，不抹掉旧记录；删除则删除该篇及历史。
8. 导出 Markdown，含正文、行动状态、已关联情况和原书来源快照，可直接放进 Obsidian。

AI 不自动确认个人事实，不自动勾选已有行动，不宣称已替用户办理手续或完成任务。界面不展示原书编辑分级，但保留出处和适用条件。

## 一个档案里存什么

| 内容 | 由谁决定 |
| --- | --- |
| 标题、生活主题、正文 | 用户主动保存，可以编辑 |
| 原书条目与关联时的来源快照 | 服务端验证真实条目，不接受模型虚构引用 |
| 个人情况及确认时间 | 用户明确确认，每次提问自行选择 |
| 行动及完成状态 | 用户手动维护 |
| 修订版本、更新时间 | 每次保存自动生成，可以预览、恢复 |

不是一份「AI 猜出来的个人画像」。目录也不是全量聊天日志；未保存的回答和草稿不是正式指南。服务端为网络失败重试保存短期加密回答缓存，不等于给用户新增一篇档案。

## 数据与会员基础

- 数据存到服务端 SQLite，不只存在当前浏览器。换浏览器访问同一服务并登录同一正式账号，才能读取同一份数据；目前尚未部署正式云端服务。
- 本机体验使用真实会话和真实数据库，明确标为「本机体验账号」，不代表邮箱已经验证。只在显式开启的非生产本机环境使用，不开放真实付款。
- 指南、情况、问答缓存加密保存；目录读取、保存、版本、导出和继续问均校验本人归属。
- 保存带版本校验，防止另一处编辑被静默覆盖；前端忽略旧账号的延迟响应。
- 免费：5 篇指南、每 30 天 10 次生成。月度/年度：100 篇、每 30 天 200 次；另有每分钟 6 次、每日 30 次、同账号同时一份回答的保护限制。
- 成功回答扣次；失败、取消和书中依据不足释放预占次数。阅读原文、检索、下载、编辑已有指南不扣生成次数。
- 会员到期，不锁住已经保存的指南；仍可编辑、查看版本、导出和删除，新建按免费容量判断。
